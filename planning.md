# FitFindr — planning.md

## Tools

### Tool 1: search_listings

**What it does:**

Searches the mock listings dataset for items matching the user's description,
optional size, and maximum price.

**Input parameters:**

- `description` (str): Keywords describing the desired item.
- `size` (str | None): Desired size, or None.
- `max_price` (float | None): Maximum price, or None.

**What it returns:**

A list of matching listing dictionaries containing fields such as title,
description, category, size, price, condition, colors, brand, and platform,
sorted by relevance.

**What happens if it fails or returns nothing:**

It returns an empty list. The planning loop tells the user no listings were
found and suggests broadening the search instead of calling later tools.

---

### Tool 2: suggest_outfit

**What it does:**

Uses the LLM to create 1–2 complete outfit suggestions using the selected
listing and the user's wardrobe.

**Input parameters:**

- `new_item` (dict): The selected listing.
- `wardrobe` (dict): User wardrobe containing an `items` list.

**What it returns:**

A non-empty string containing outfit recommendations.

**What happens if it fails or returns nothing:**

An empty wardrobe receives general styling advice using common clothing pieces.
LLM errors are caught by the agent and returned as an informative error.

---

### Tool 3: create_fit_card

**What it does:**

Uses the LLM to turn the outfit suggestion into a short social-media-ready
caption.

**Input parameters:**

- `outfit` (str): Outfit suggestion generated by suggest_outfit.
- `new_item` (dict): Selected listing.

**What it returns:**

A 2–4 sentence casual fit-card caption mentioning the item, price, platform,
and outfit vibe.

**What happens if it fails or returns nothing:**

If outfit is empty, it returns an informative error string instead of crashing.

---

## Planning Loop

The agent first parses the query for a description, size, and maximum price.
It calls `search_listings` using those values. If there are no results, the
agent stores an error and stops without calling the other tools.

If results exist, the agent selects the highest-ranked listing and stores it
in session state. It passes that exact item and the wardrobe to
`suggest_outfit`. The resulting outfit is stored in session state and passed
to `create_fit_card`. The completed session is then returned.

## State Management

A session dictionary stores the original query, parsed parameters, search
results, selected item, wardrobe, outfit suggestion, fit card, and error.
The selected listing from the search result becomes the `new_item` input to
suggest_outfit. The resulting outfit string becomes the `outfit` input to
create_fit_card.

## Error Handling

| Tool            | Failure mode   | Agent response                                                             |
| --------------- | -------------- | -------------------------------------------------------------------------- |
| search_listings | No results     | Tell the user no listings matched and suggest broader search criteria.     |
| suggest_outfit  | Empty wardrobe | Generate general styling advice instead of requiring wardrobe items.       |
| create_fit_card | Missing outfit | Return an informative error instead of calling the LLM with invalid input. |

## A Complete Interaction (Step by Step)

**Example user query:** "I'm looking for a vintage graphic tee under $30. I mostly wear baggy jeans and chunky sneakers."

**Step 1:**

The agent parses the query to identify the description ("vintage graphic tee")
and maximum price ($30). It calls `search_listings(description, size, max_price)`
with those values. The returned listings are sorted by relevance, and the top
matching listing is selected.

**Step 2:**

The selected listing is stored in session state as `selected_item`. The agent
passes that exact listing and the user's wardrobe to
`suggest_outfit(new_item, wardrobe)`. The tool returns one or more complete
outfit suggestions.

**Step 3:**

The outfit suggestion is stored in session state as `outfit_suggestion`. The
agent passes that string and the same selected listing to
`create_fit_card(outfit, new_item)`. The tool generates a short, casual,
shareable caption.

**Final output to user:**

The user sees the top matching listing, the outfit recommendation, and the
final fit-card caption.

**No-results path:**

If `search_listings` returns an empty list, the agent stores an error message
in the session and stops. It does not call `suggest_outfit` or
`create_fit_card` with missing data.
